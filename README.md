# 3D Solar System & Spaceship Flight Simulator

An interactive 3D WebGL simulation built with **Three.js** featuring a procedurally rendered solar system with orbiting planets, an emissive Sun, and a pilotable spacecraft.

## 🚀 Features

- **Procedural Solar System:** Explore the Sun and all 8 orbiting planets (Mercury, Venus, Earth, Mars, Jupiter, Saturn with custom rings, Uranus, and Neptune).
- **Spaceship Flight Simulator:** Take the controls of an exploration cruiser in deep space.
- **Dynamic Lighting & Starfield:** Immersive star background with real-time planetary orbits and lighting.

---

## 🕹️ How to Play & Controls

Open the live simulation in your browser, then use your keyboard to pilot your spacecraft:

| Key | Action |
| :--- | :--- |
| **W** / **S** | Thrust Forward / Reverse |
| **A** / **D** | Steer Left / Right |
| **SPACE** | Ascend / Elevate Up |
| **SHIFT** | Descend / Lower Down |
